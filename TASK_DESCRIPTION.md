## 1. ПРОЕКТ: Вертикальная CRM для арендодателей 5-50 объектов

### Суть
Простая платформа для малых арендодателей: жилье, коммерческие помещения, склады, студии, техника. Не enterprise-решение, а удобный кабинет для аренды, платежей, договоров, заявок на ремонт и напоминаний.

### Для кого
- владельцы 5-50 квартир
- управляющие посуточной аренды
- владельцы коммерческих помещений
- небольшие управляющие компании
- прокатные бизнесы

### Что делает (MVП)
1. Ведет объекты и арендаторов
2. Напоминает об оплате
3. Хранит договоры
4. Принимает заявки на ремонт
5. Фиксирует платежи
6. Показывает доходность по объектам
7. Напоминает о продлении договора
8. Отправляет уведомления арендаторам

### Монетизация
- 1490-4990 рублей в месяц
- тариф по количеству объектов
- платные шаблоны документов
- комиссия с платежей

### Оценка
- Потенциал рынка: высокий
- Сложность MVP: средняя
- Риск конкуренции: средний
- Шанс быстрого дохода: средний-высокий

  - Безопасность (ФЗ-152, 54-ФЗ, шифрование)

  - Что упущено — добавить
- Сохранить аналитику в analytics/analytics.md

### Этап 2: SDD Спецификация
На основе аналитики подготовить SDD (Software Design Document) по подходу https://github.com/github/spec-kit
Спецификация должна быть готова к внедрению в PRODUCTION сразу после реализации.
Продумать детально:

**Стек технологий:**
- Фронтенд: TypeScript, React, MobX
- Мобильное приложение: React Native, TypeScript, MobX (если требуется)
- Бекенд: Java, Spring Boot
- База данных: PostgreSQL
- Деплой: Docker Compose

**Спецификация должна содержать:**
- Архитектура (C4 model или аналогично)
- ERD / Модели данных
- API endpoints (REST)
- UI/UX описание (экраны, flow)
- Безопасность
- Интеграции (платежи, СМС, email, Telegram)
- Асинхронные задачи (уведомления, напоминания)
- CI/CD
- Мониторинг

Сохранить в specification/sdd.md

- CRM для коммерческой недвижимости (офисы, ТЦ, склады)

#### 2. Renda (renda.su)
