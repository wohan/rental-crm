# Design refresh 2026

Дата: 2026-06-14

Цель: привести визуальный стиль RentCRM к актуальному виду B2B SaaS/enterprise-сервиса без превращения продукта в маркетинговый лендинг.

## Ориентиры

1. Design tokens: цвета, тени, границы и состояния задаются через единые CSS-переменные.
2. Нейтральная рабочая среда: светлый фон, белые поверхности, аккуратные границы, меньше декоративности.
3. Цвет по назначению:
   - синий: основное действие и навигация;
   - зеленый: успех/оплачено;
   - красный: ошибки/опасные действия;
   - синий информационный: промежуточные статусы.
4. Компактность для операционного SaaS: карточки и строки должны хорошо сканироваться при большом количестве объектов.
5. Не использовать декоративные градиенты, орбы и псевдо-landing композицию в рабочем кабинете.

## Что изменено

1. Убран доминирующий зелено-бежевый стиль.
2. Добавлены CSS design tokens в `frontend/src/styles/app.css`.
3. Обновлены цвета фона, карточек, границ, фокуса, кнопок, навигации и статусов.
4. Статусы получили отдельные семантические цвета.
5. Интерфейс стал ближе к современному B2B SaaS: спокойный, чистый, менее декоративный, лучше подходит для ежедневной работы.

## Что стоит сделать дальше

1. Перевести списки в полноценные data tables с toolbar, поиском, фильтрами и пагинацией.
2. Вынести создание/редактирование в drawer или modal.
3. Добавить плотный/комфортный режим отображения.
4. Сделать mobile navigation через bottom navigation + меню "Еще".
5. Добавить skeleton/loading states вместо резких пустых экранов.
